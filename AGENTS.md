# CodeGraph MCP Tools

CodeGraph tools are available via MCP for codebase exploration and analysis.

## Available Tools

- `codegraph_context` — Get context for a symbol (function, class, etc.)
- `codegraph_trace` — Trace a call path from source to database or external API
- `codegraph_explore` — Explore files, directories, and their relationships
- `codegraph_callers` — Find all callers of a function or method
- `codegraph_callees` — Find all callees (subcalls) of a function
- `codegraph_impact` — Analyze impact of changes to a symbol or file
- `codegraph_search` — Full-text search across the codebase

## Usage

When asked about how parts of the codebase connect, use CodeGraph tools to trace the flow instead of relying on guesswork or the explore sub-agent.
